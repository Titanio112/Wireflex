# Wireflex

[Português](#português) · [English](#english)

---

## Português

> **Status:** em desenvolvimento. Ainda não há versão para uso.

O Wireflex é um aplicativo de bandeja do Windows que espelha celulares Android no PC usando o [scrcpy](https://github.com/Genymobile/scrcpy). Ele conecta sozinho, por cabo USB ou Wi-Fi, e suporta vários celulares.

### Créditos
- [scrcpy](https://github.com/Genymobile/scrcpy), da Genymobile: o espelhamento de tela.
- [scrcpy-auto-switch](https://github.com/Titanio112/scrcpy-auto-switch): o projeto de origem (v1), do qual o Wireflex é uma reescrita.

## English

> **Status:** under development. No usable release yet.

Wireflex is a Windows tray app that mirrors Android phones on your PC using [scrcpy](https://github.com/Genymobile/scrcpy). It connects automatically over USB cable or Wi-Fi and supports multiple phones.

### Credits
- [scrcpy](https://github.com/Genymobile/scrcpy) by Genymobile: the screen mirroring.
- [scrcpy-auto-switch](https://github.com/Titanio112/scrcpy-auto-switch): the original project (v1), which Wireflex rewrites from scratch.
